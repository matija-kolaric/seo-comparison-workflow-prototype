# Suggested 5–10 minute review path

1. Read the architecture diagram and workflow summary in the README.
2. Open `skills/comparison-research/SKILL.md` and `skills/comparison-qa/SKILL.md` to see the research and evaluation boundaries.
3. Open `skills/comparison-orchestrator/SKILL.md` and `src/seobility_workflow/orchestrator.py` to see how stage handoffs, approvals and budget controls are applied.
4. Review `tests/test_orchestrator.py` and `tests/test_topic_selection.py` for representative failure and control cases.
5. Visit the live preview to see the published comparison pages and browser-only tool-fit selector.

The synthetic samples and fixtures are deliberately non-production. They show input and artifact structure without presenting sample values as real market findings.
