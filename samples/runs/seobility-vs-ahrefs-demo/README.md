# Seobility vs Ahrefs demo run

This directory is a behavioral fixture, not real product research and not publishable content.

It demonstrates:

1. normalized SERP and product-research inputs;
2. an authoritative JSON brief with a Markdown rendering;
3. a first draft containing an intentionally unsupported claim;
4. a failed fact and quality review;
5. a consolidated revision request;
6. a corrected second draft;
7. passing QA and a stop at `awaiting_human_approval`.

DataForSEO can later replace `research/serp.json` through either API or MCP after response normalization. WordPress publishing remains absent because the fixture has no human approval record. A WordPress API or MCP can create the staging draft later, with Playwright used only when browser-level validation adds evidence unavailable from the publishing interface.
